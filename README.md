# NLP-Based Supplier Risk Analysis

## Project Overview

This project applies Natural Language Processing (NLP) and quantitative risk modelling to analyse supplier-related incidents across automobile companies. It examines incident descriptions, identifies recurring risk patterns and evaluates supplier disruption risks using text analytics, time series analysis and Monte Carlo simulation.

## Project Objectives

- Identify frequently occurring supplier risk keywords.
- Analyse supplier incident patterns across companies.
- Examine monthly trends in supplier risk incidents.
- Develop NLP-based supplier risk scores.
- Forecast supplier risk incidents using time series modelling.
- Evaluate potential supply chain disruptions through Monte Carlo simulations and stress testing.

## Tools & Technologies

- Python
- Pandas and NumPy
- spaCy
- Scikit-learn (TF-IDF)
- Matplotlib and Seaborn
- Statsmodels
- Jupyter Notebook

## Methodology

### 1. Text Preprocessing
Applied text cleaning, tokenisation, lemmatisation and stop-word removal using spaCy.

### 2. Keyword Frequency Analysis
Identified frequently occurring supplier risk keywords and compared keyword patterns across companies.

### 3. TF-IDF Analysis
Used Term Frequency–Inverse Document Frequency to extract important terms from supplier incident descriptions.

### 4. Supplier Risk Scoring
Developed a weighted NLP-based risk scoring approach using incident-related keywords and aggregated supplier-level risk scores.

### 5. Time Series Analysis
Examined monthly supplier incident trends, conducted Augmented Dickey-Fuller (ADF) stationarity testing and applied an ARIMA(1,1,1) model for forecasting.

### 6. Monte Carlo Simulation
Used simulation-based risk modelling to estimate expected risk, volatility and 95% Value at Risk (VaR).

### 7. Stress Testing
Evaluated hypothetical logistics, quality and systemic supply crisis scenarios to understand their potential impact on supplier risk.

## Key Analytical Components

- Supplier risk keyword extraction
- Company-wise incident analysis
- Monthly incident trend analysis
- NLP-based risk scoring
- ARIMA forecasting
- Monte Carlo risk simulation
- Scenario-based stress testing

## Project Deliverables

- Jupyter Notebook containing Python-based analysis.
- Project presentation explaining the analytical approach and findings.

## Conclusion

The project demonstrates how NLP techniques can transform unstructured supplier incident descriptions into structured risk indicators. By combining text analytics, time series forecasting and simulation-based modelling, the analysis provides a framework for examining supplier risk patterns and potential supply chain disruptions.
